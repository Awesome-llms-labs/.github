# Awesome-llms-labs 🧪

Welcome! We're a small research lab curating **research-backed awesome-lists for the LLM landscape**. Every entry is verified against official sources — or explicitly flagged when it isn't. No invented specs, no hype-only entries.

## The family

| List | What it covers |
|---|---|
| [awesome-decisions-llms](https://github.com/awesome-llms-labs/awesome-decisions-llms) | LLMs for decision-making: decision-tuned models, benchmarks & evals, frameworks |
| [awesome-fast-llms](https://github.com/awesome-llms-labs/awesome-fast-llms) | Inference-speed LLMs: models, providers, engines, optimization techniques |
| [awesome-flagship-llms](https://github.com/awesome-llms-labs/awesome-flagship-llms) | Frontier flagship models, benchmark notes, verified pricing |
| [awesome-flash-llms](https://github.com/awesome-llms-labs/awesome-flash-llms) | Flash-class efficiency models + where to deploy and serve them |
| [awesome-free-llms](https://github.com/awesome-llms-labs/awesome-free-llms) | Genuinely free LLMs: free API tiers, free chat apps, open-weight local models |
| [awesome-ai-agents](https://github.com/awesome-llms-labs/awesome-ai-agents) | The AI agent ecosystem: frameworks, tools, and platforms |
| [awesome-ai-sandboxes](https://github.com/awesome-llms-labs/awesome-ai-sandboxes) | AI sandboxes: managed, open-source, and browser-based |
| [awesome-jev](https://github.com/awesome-llms-labs/awesome-jev) | TypeSafe's Jev (System One): docs, examples, and resources |
| [awesome-microVM](https://github.com/awesome-llms-labs/awesome-microVM) | The microVM ecosystem, from Firecracker to macOS-native runtimes |
| [awesome-prompt-engineering](https://github.com/awesome-llms-labs/awesome-prompt-engineering) | Prompt engineering: techniques, patterns, and guides |
| [awesome-llm-observability](https://github.com/awesome-llms-labs/awesome-llm-observability) | LLM observability: tracing, evals-ops, and monitoring |
| [awesome-multimodal-llms](https://github.com/awesome-llms-labs/awesome-multimodal-llms) | Multimodal and vision-capable LLMs |
| [awesome-AI-agent-orchestration](https://github.com/awesome-llms-labs/awesome-AI-agent-orchestration) | The agent coordination layer: orchestration frameworks, protocols, memory, platforms, evals, and papers |
| [awesome-multi-agents-workflow](https://github.com/awesome-llms-labs/awesome-multi-agents-workflow) | Multi-agent collaboration: crews, swarms, supervisor teams, protocols, and the infrastructure that runs them |
| [awesome-oss-macos](https://github.com/awesome-llms-labs/awesome-oss-macos) | Open-source macOS applications: 80 apps across 10 categories, all licenses verified |
| [awesome-rag](https://github.com/awesome-llms-labs/awesome-rag) | Retrieval-augmented generation: vector stores, embeddings, chunking, frameworks, and evals |
| [awesome-startup-credits](https://github.com/awesome-llms-labs/awesome-startup-credits) | Startup credit programs: cloud infra, AI API credits, devtools, and cash grants |

All lists are public and MIT-licensed, ship machine-readable JSON data, docs, and green CI. Start with the [meta-index](https://github.com/awesome-llms-labs/awesome-llms) for the guided tour.

## Contributing

Every repo has a `CONTRIBUTING.md`. New entries must cite an official source; unverified entries are flagged, never fabricated. PRs welcome!
